# TurboBoost 3.0

Геймерский оптимизатор Android (Shizuku): турбо, растяг, прицел, комфорт, оверлеи, диагностика.

## Что нового в 3.0

### Интерфейс
- Карточный UI в стиле StandVisuals: тёмная тема, синий акцент **Сталь**
- Нижняя навигация: **Турбо · Растяг · Прицел · Игра · Диагн. · Ещё**
- Логотип TurboBoost (молния), adaptive icon

### Растяг
- Профили **4:3 / 5:4 / 1:1** (сильные)
- Режим планшета
- Автосброс по 100% (два подтверждения + 5 с, аварийно 90 с)
- Тест 3 секунды, ручной возврат разрешения
- Приоритет растяга над снижением разрешения

### Прицел
- Формы: крест, T, точка, сердце, квадрат/ромб, круг
- 25 цветов
- Длина, толщина, отступ, прозрачность, обводка, масштаб
- Вкл/выкл верхней / нижней / левой / правой линии
- Код прицела (копировать / вставить)
- Оверлей поверх игры

### Турбо (ваши функции)
- Max performance, GPU boost, Hz, сенса
- Unlock FPS, pin to prime core, SurfaceFlinger boost, ping
- Снижение нагрузки: Без изм. / Чётко / Баланс / Быстро / Макс.
- Полный откат `revertAll`
- QS-тайл, KeepAlive, авто-сессия

### Игра
- Кнопка-шестерёнка в игре
- Комфорт: яркость, DND, не гасить экран, контраст, восстановление после игры
- Пинг + FPS HUD
- Звуки убийств (MediaProjection — флаг)
- Треки (плейлист UI)

### Диагностика
- Состояние устройства / Shizuku / Overlay / Usage
- Детектор 100%, Game Mode, ровность кадров, FPS

## Сборка
```bash
./gradlew assembleRelease
```
Нужен `release.jks` и env: `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.

## Требования
- Android 8.0+ (API 26)
- [Shizuku](https://shizuku.rikka.app/) для системных твиков
- Разрешение оверлея для прицела / HUD
- Usage access для авто-сессии

## Важно
Приложение **не** изменяет клиент игры. Только системные настройки через Shizuku и оверлеи.
